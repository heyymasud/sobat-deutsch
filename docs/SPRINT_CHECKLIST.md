## Legenda status

`[ ]` belum mulai · `[~]` sedang dikerjakan · `[x]` **DONE** (semua gate lolos) · `[!]` blocked (tulis alasannya)

## Gate commands

Semua gate WAJIB exit code 0 sebelum task apa pun boleh ditandai `[x]`.

| Gate | Command | Status |
|---|---|---|
| build | `npm run build` | OK |
| typecheck | `npm run typecheck` | OK |
| lint | `npm run lint` | OK |
| test | `npm run test` | OK |

**Mengisi keempat command di atas adalah bagian dari Definition of Done task S1-01** — sampai terisi, tidak ada task lain yang boleh ditandai `[x]`.

## Aturan menandai DONE (berlaku juga kalau kamu hanya membaca file ini)

Task boleh ditandai `[x]` HANYA kalau **semua** ini benar:

1. Seluruh gate command di atas dijalankan dan **exit 0**.
2. **Tidak ada error baru DAN tidak ada warning baru** dibanding sebelum task ini dikerjakan.
3. Acceptance Criteria (`AC-*`) yang dirujuk task **diverifikasi dengan dijalankan**, bukan dibaca lalu disimpulkan.
4. Field `bukti:` diisi — perintah yang dijalankan + ringkasan hasilnya. **Klaim tanpa bukti tidak dihitung DONE.**

**Kalau ada gate gagal:** tandai `[!]` + tulis alasannya. JANGAN tandai `[x]`.

**DILARANG** melonggarkan gate supaya lolos (skip test, disable lint rule, `--no-verify`, ubah tipe jadi `any`, dst). Gate gagal → perbaiki akar masalahnya atau tandai blocked.
